# Changelog

## 0.2.0 — Mac support and installation-first documentation

- Separate Mac installation entry with managed Python, hash-locked dependencies and native Keychain storage.
- Apple Silicon and Intel macOS CI, including cold startup, credential rotation and offline warm startup.
- English and Chinese quick starts, detailed installation guides, real plugin screenshot and original vector headers.
- Shorter plugin title and shared connector/skill synchronization across platform entries.
- Windows embedded runtime refreshed with the shared connector; upstream MCP remains 0.6.2.

## 0.1.0 — Initial GitHub distribution

- Separate QuantDinger Codex plugin marketplace and source repository.
- English and Simplified Chinese installation and usage guides.
- Windows x64 runtime with Python 3.13.15 and quantdinger-mcp 0.6.2.
- Credential connector, four workflow skills and isolated regression tests.
- macOS packaging is planned and is not included in this release.

The MCP service has an independent version history in the upstream repository.
